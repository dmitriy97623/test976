# Контроллер давления на Arduino Nano

Проект контроллера давления для управления технологическими процессами на базе Arduino Nano V3. 
Устройство считывает сигнал 4-20 мА с преобразователя давления, отображает текущие значения 
на ЖК-дисплее 1602 I2C и управляет двумя электромагнитными клапанами через релейные модули.


## 🛠 Функциональные возможности

*   **Чтение датчика:** Поддержка преобразователей давления с токовым выходом 4-20 мА (питание 24 В).
*   **Управление нагрузкой:** Два независимых реле (D2, D3) для управления клапанами или насосами.
*   **Интерфейс:** ЖК-дисплей 1602 с модулем I2C.
*   **Быстрый поразрядный ввод:** Удобное редактирование уставок и гистерезиса цифра за цифрой.
*   **Настройки в реальном времени:**
    *   Выбор диапазона измерения (Ранг): 1, 40, 250, 400, 600, 1000.
    *   Выбор единиц измерения: Па, кПа, МПа, бар, мбар.
    *   Настройка нижней и верхней уставки с визуальным выбором разряда.
    *   Отдельная настройка зоны нечувствительности (Гистерезис).
*   **Калибровка:** Двухточечная калибровка (0% и 100%) прямо через меню.
*   **Защита и диагностика:**
    *   Детекция обрыва цепи датчика (ток < 4 мА).
    *   Аварийное отключение реле при неисправности.
*   **Энергонезависимая память:** Все настройки сохраняются в EEPROM.
*   **Сброс настроек:** Возврат к заводским параметрам.

## 🔌 Схема подключения (Распиновка)


### Питание и Датчик
*   **БП 24В (+)** -> Питание датчика (+) и общий контакт реле (COM).
*   **БП 24В (-)** -> Земля (GND) Arduino, Земля датчика (-), Минус клапанов.
*   **Сигнал датчика** -> Резистор 240 Ом -> GND. Точка соединения -> **A0**.


### Периферия Arduino Nano
| Пин Arduino | Компонент | Описание |
| :--- | :--- | :--- |
| **A0** | Датчик (через резистор) | Аналоговый вход сигнала |
| **A4** | LCD SDA | Шина данных I2C |
| **A5** | LCD SCL | Шина тактирования I2C |
| **D2** | Реле 1 (IN1) | Управление Клапаном 1 |
| **D3** | Реле 2 (IN2) | Управление Клапаном 2 |
| **D4** | Кнопка MENU | Навигация / Выбор разряда / Подтверждение |
| **D5** | Кнопка CHANGE | Изменение цифры / Значения |
| **5V** | LCD VCC, Реле VCC | Питание логики |
| **GND** | LCD GND, Реле GND, Кнопки | Общая земля |


## 🎛 Управление и Меню

Устройство управляется двумя кнопками с интеллектуальной логикой в зависимости от контекста.

### 1. Режим просмотра (Основной экран)
*   **MENU (Короткое):** Переключение пунктов меню (Mode -> Range -> Setpoint -> Unit -> Calibr -> Reset).
*   **MENU (Длинное > 2 сек):** Вход в режим редактирования выбранного пункта.

### 2. Режим редактирования (Портазрядный ввод для чисел)
Используется для уставок (Low/High) и Гистерезиса.
*   **CHANGE:** Увеличивает цифру в текущем активном разряде (0 → 1 → ... → 9 → 0).
*   **MENU (Короткое):** Перемещает курсор (мигающий символ) по разрядам слева направо (Сотни → Десятки → Единицы → Десятые).
    *   *После последнего разряда короткое нажатие MENU подтверждает ввод и сохраняет значение.*
*   **MENU (Длинное):** Экстренный выход из режима редактирования без сохранения изменений.

### 3. Режим редактирования (Выбор из списка)
Используется для Ранга, Единиц измерения.
*   **CHANGE:** Перебор доступных вариантов по кругу.
*   **MENU (Короткое/Длинное):** Подтверждение выбора и переход к следующему пункту или выход.


### Структура меню
1.  **Mode:** Информационный экран (текущее давление, состояние реле).
2.  **Range:** Выбор максимального диапазона датчика.
3.  **Setpoint:** Настройка уставок.
    *   Выбор уставки: `L` (Нижняя) или `H` (Верхняя).
    *   **Ввод значения:** Портазрядный ввод (например, `_ _ _ . _`).
    *   **Гистерезис:** Отдельный подпункт для настройки зоны нечувствительности.
4.  **Unit:** Выбор единиц измерения (Pa, kPa, MPa, bar, mbar).
5.  **Calibr:** Калибровка нуля (4 мА) и максимума (20 мА).
6.  **Reset:** Сброс всех настроек к заводским значениям.


## ⚙️ Логика работы

*   **Реле 1 (Клапан 1):** Активно, когда давление ниже `Уставка Low - Гистерезис`.
*   **Реле 2 (Клапан 2):** Активно, когда давление выше `Уставка High + Гистерезис`.
*   **Авария:** При обрыве датчика (< 4 мА) выводится `ERR BREAK`, реле отключаются.


## 💾 Память (EEPROM)

Настройки сохраняются автоматически после подтверждения ввода (переход курсора за последний разряд).
Используются адреса EEPROM для хранения версии прошивки, калибровочных коэффициентов и пользовательских настроек.


## 🔧 Установка библиотек

Для работы скетча в Arduino IDE необходимо установить библиотеку:

1.  Откройте **Меню** -> **Скетч** -> **Подключить библиотеку** -> **Управление библиотеками**.
2.  Найдите и установите: **LiquidCrystal I2C** (автор: Frank de Brabander).
