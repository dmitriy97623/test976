# Контроллер давления v4.0

Автоматический контроллер давления для Arduino Nano с поддержкой датчиков 4-20 мА, LCD 1602 I2C и двумя реле.

---

## 📋 Описание

Контроллер автоматически поддерживает давление в заданном диапазоне, управляя двумя клапанами:
- **Реле 1** — входной клапан (накачивает давление)
- **Реле 2** — выпускной клапан (сбрасывает давление)

---

## 🎯 Принцип работы

### 1️⃣ Давление НИЖЕ рабочей зоны (< setpointLow - hysteresis)

```
┌─────────────────────────────────────┐
│ Давление: 200 mbar                  │
│ Состояние: СЛИШКОМ НИЗКОЕ           │
│                                     │
│ Реле 1 (вход)  → ОТКРЫТО  ✅        │
│ Реле 2 (выпуск)→ ЗАКРЫТО   ❌       │
│                                     │
│ Действие: НАКАЧИВАТЬ ДАВЛЕНИЕ       │
└─────────────────────────────────────┘
```

### 2️⃣ Давление в рабочей зоне (setpointLow - hyst ≤ P ≤ setpointHigh + hyst)

```
┌─────────────────────────────────────┐
│ Давление: 290 mbar                  │
│ Состояние: НОРМА (в диапазоне)      │
│                                     │
│ Реле 1 (вход)  → ЗАКРЫТО   ❌       │
│ Реле 2 (выпуск)→ ЗАКРЫТО   ❌       │
│                                     │
│ Действие: НИЧЕГО НЕ ДЕЛАТЬ          │
└─────────────────────────────────────┘
```

### 3️⃣ Давление ВЫШЕ рабочей зоны (> setpointHigh + hysteresis)

```
┌─────────────────────────────────────┐
│ Давление: 350 mbar                  │
│ Состояние: СЛИШКОМ ВЫСОКОЕ          │
│                                     │
│ Реле 1 (вход)  → ЗАКРЫТО   ❌       │
│ Реле 2 (выпуск)→ ОТКРЫТО  ✅        │
│                                     │
│ Действие: СБРАСЫВАТЬ ДАВЛЕНИЕ       │
└─────────────────────────────────────┘
```

## ⚙️ Настройки

| Параметр | Значение | Описание |
|---|---|---|
| **Range** | 400.0 | Максимальное давление (диапазон датчика) |
| **Unit** | mbar | Единицы измерения |
| **SpLow** | 280.0 | Нижняя уставка (начало рабочей зоны) |
| **SpHigh** | 300.0 | Верхняя уставка (конец рабочей зоны) |
| **Hyst** | 20.0 | Гистерезис (защита от частых переключений) |

---

## 🔧 Как настроить

1. **Войти в меню:** Длинное нажатие **MENU** (1.5 сек)
2. **Выбрать Range:** MENU → `1.Range` → CHANGE → выбрать `400` → MENU
3. **Выбрать Unit:** MENU → `5.Unit` → CHANGE → выбрать `mbar` → MENU
4. **Задать SpLow:** MENU → `2.SpLow` → CHANGE → ввести `280.0` → MENU
5. **Задать SpHigh:** MENU → `3.SpHigh` → CHANGE → ввести `300.0` → MENU
6. **Задать Hyst:** MENU → `4.Hyst` → CHANGE → ввести `20.0` → MENU

### Формат ввода уставок
- Формат: `XXX.X` (три цифры, точка, одна цифра)
- Пример: `280.0` вводится как `2` → `8` → `0` → `0`
- Мигающий курсор показывает активную цифру

## ⚠️ Безопасность

- **Обрыв датчика:** Оба реле закрываются
- **Перезагрузка:** Оба реле выключены при старте
- **Watchdog Timer:** При зависании — автоматическая перезагрузка через 2 сек
- **Индикация сброса:** На дисплее отображается `WDT RESET!` после перезагрузки от Watchdog

## 🚀 Установка

1. Установить Arduino IDE
2. Добавить поддержку Arduino Nano:
   - File → Preferences → Additional Boards Manager URLs
   - Добавить: `http://arduino.esp8266.com/stable/package_esp8266com_index.json`
   - Tools → Board → Boards Manager → найти "Arduino AVR Boards"
3. Подключить Arduino Nano к ПК
4. Выбрать порт и плату: Tools → Board → Arduino Nano
5. Загрузить скетч: Sketch → Upload
