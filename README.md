# Контроллер давления на Arduino Nano

Проект контроллера давления для управления технологическими процессами на базе Arduino Nano V3.
Устройство считывает сигнал 4-20 мА с преобразователя давления, отображает текущие значения
на ЖК-дисплее 1602 I2C и управляет двумя электромагнитными клапанами через релейные модули.


## 🛠 Функциональные возможности

*   **Чтение датчика:** Поддержка преобразователей давления с токовым выходом 4-20 мА (питание 24 В).
*   **Управление нагрузкой:** Два независимых реле (D2, D3) для управления клапанами или насосами.
*   **Интерфейс:** ЖК-дисплей 1602 с модулем I2C.
*   **Быстрый поразрядный ввод:** Удобное редактирование уставок и гистерезиса цифра за цифрой.
*   **Настройки в реальном времени:**
    *   Выбор диапазона измерения (Ранг): 1, 40, 250, 400, 600, 1000.
    *   Выбор единиц измерения: Па, кПа, МПа, бар, мбар.
    *   Настройка нижней и верхней уставки с визуальным выбором разряда.
    *   Отдельная настройка зоны нечувствительности (Гистерезис).
*   **Калибровка:** Двухточечная калибровка (0% и 100%) прямо через меню.
*   **Защита и диагностика:**
    *   Детекция обрыва цепи датчика (ток < 4 мА).
    *   Аварийное отключение реле при неисправности.
*   **Энергонезависимая память:** Все настройки сохраняются в EEPROM.
*   **Сброс настроек:** Возврат к заводским параметрам (с подтверждением).
*   **Безопасность на опасном объекте:**
    *   Реле управляются ВСЕГДА — даже в меню настроек.
    *   Таймаут возврата из меню (30 с просмотр, 60 с редактирование).
    *   Двухшаговое подтверждение опасных действий (Reset, Calibr).
    *   Обрыв датчика — аварийный экран, реле отключены.

## 🔌 Схема подключения (Распиновка)

### Питание и Датчик
*   **БП 24В (+)** -> Питание датчика (+) и общий контакт реле (COM).
*   **БП 24В (-)** -> Земля (GND) Arduino, Земля датчика (-), Минус клапанов.
*   **Сигнал датчика** -> Резистор 240 Ом -> GND. Точка соединения -> **A0**.

### Периферия Arduino Nano
| Пин Arduino | Компонент | Описание |
| :--- | :--- | :--- |
| **A0** | Датчик (через резистор) | Аналоговый вход сигнала |
| **A4** | LCD SDA | Шина данных I2C |
| **A5** | LCD SCL | Шина тактирования I2C |
| **D2** | Реле 1 (IN1) | Управление Клапаном 1 |
| **D3** | Реле 2 (IN2) | Управление Клапаном 2 |
| **D4** | Кнопка MENU | Навигация / Подтверждение |
| **D5** | Кнопка CHANGE | Изменение значения / Ввод |
| **5V** | LCD VCC, Реле VCC | Питание логики |
| **GND** | LCD GND, Реле GND, Кнопки | Общая земля |


## 🎛 Управление и Меню

Управление построено по промышленному стандарту (Omron, Danfoss, WIKA, Элемер):
машина состояний с чётким разделением навигации и редактирования.

### Кнопки

| Кнопка | Короткое нажатие | Длинное нажатие (>1.5 с) |
| :--- | :--- | :--- |
| **MENU** | Навигация: следующий пункт / следующий разряд | Вход в меню / Подтверждение / Выход |
| **CHANGE** | Изменить: +1 к значению / Показать уставки | Декремент цифры (при вводе числа) |

### Состояния устройства

```
┌──────────┐  MENU дл.   ┌──────────────┐  CHANGE     ┌──────────────┐
│  РАБОЧИЙ  │────────────►│  ПРОСМОТР    │────────────►│  РЕДАКТИР.   │
│  ЭКРАН    │◄────────────│  МЕНЮ        │◄────────────│              │
└──────────┘  MENU дл. /  └──────────────┘  MENU дл.   └──────────────┘
              таймаут         │      ▲         (отмена)     │  ▲
                               │      │                      │  │
                           CHANGE│      │                  MENU│  │CHANGE
                           коротк.│     │               коротк.│  │длинн.
                               └──────┘──────────────────────┘  │
                                  (подтвердить)            (декремент)
```

### 1. Рабочий экран (основной режим)

На экране: текущее давление и состояние реле.
*   **MENU длинное:** Вход в меню настроек.
*   **CHANGE короткое:** Показать уставки (Lo → Hi → давление). Автовозврат через 3 с.

### 2. Просмотр меню (навигация)

На экране: название пункта и текущее значение.
*   **MENU короткое:** Следующий пункт меню.
*   **MENU длинное:** Выход в рабочий экран.
*   **CHANGE короткое:** Войти в редактирование выбранного пункта.
*   **Таймаут:** 30 с бездействия → автовозврат в рабочий экран.

### 3. Редактирование — выбор из списка (Range, Unit)

*   **CHANGE короткое:** Перебор вариантов по кругу.
*   **MENU короткое:** Подтвердить выбор → вернуться в просмотр.
*   **MENU длинное:** Отмена → вернуться без сохранения.

### 4. Редактирование — поразрядный ввод (SpLow, SpHigh, Hyst)

*   **CHANGE короткое:** +1 к текущей цифре.
*   **CHANGE длинное:** −1 к текущей цифре.
*   **MENU короткое:** Следующий разряд. После последнего — подтвердить и сохранить.
*   **MENU длинное:** Отмена без сохранения → вернуться в просмотр.

### 5. Подтверждение опасного действия (Reset, Calibr)

На экране: `!! RESET ALL !!` / `!! CALIBRATE !!`
*   **MENU длинное:** Подтвердить действие.
*   **MENU короткое / CHANGE:** Отмена → вернуться в просмотр.

### Структура меню

| № | Пункт | Тип ввода | Описание |
|---|---|---|---|
| 1 | Range | Выбор из списка | Диапазон датчика (1, 40, 250, 400, 600, 1000) |
| 2 | SpLow | Поразрядный | Нижняя уставка |
| 3 | SpHigh | Поразрядный | Верхняя уставка |
| 4 | Hyst | Поразрядный | Гистерезис |
| 5 | Unit | Выбор из списка | Единицы измерения (Pa, kPa, MPa, bar, mbar) |
| 6 | Calibr | Подтверждение | Калибровка (0% и 100%) |
| 7 | Reset | Подтверждение | Сброс всех настроек к заводским |


## ⚙️ Логика работы

*   **Реле 1 (Клапан 1):** Активно, когда давление ниже `Уставка Low - Гистерезис`.
*   **Реле 2 (Клапан 2):** Активно, когда давление выше `Уставка High + Гистерезис`.
*   **Авария:** При обрыве датчика (< 4 мА) выводится `ERR BREAK`, реле отключаются.
*   **Безопасность:** Управление реле работает ВСЕГДА, даже если пользователь в меню.


## 💾 Память (EEPROM)

Настройки сохраняются автоматически при подтверждении ввода.
Используются адреса EEPROM для хранения калибровочных коэффициентов и пользовательских настроек.


## 🔧 Установка библиотек

Для работы скетча в Arduino IDE необходимо установить библиотеку:

1.  Откройте **Меню** -> **Скетч** -> **Подключить библиотеку** -> **Управление библиотеками**.
2.  Найдите и установите: **LiquidCrystal I2C** (автор: Frank de Brabander).

## 🏗 Архитектура проекта

Проект разделён на три логических слоя.
Все файлы находятся в папке `pressure_controller/` для совместимости с Arduino IDE.

### 1. `hardware` — Работа с «железом»
- **Файлы:** `hardware.h`, `hardware.cpp`
- Инициализация пинов, чтение АЦП, управление реле, EEPROM.

### 2. `logic` — Бизнес-логика
- **Файлы:** `logic.h`, `logic.cpp`
- Расчёт давления, логика реле по уставкам, диапазоны и единицы.

### 3. `ui` — Пользовательский интерфейс
- **Файлы:** `ui.h`, `ui.cpp`
- Машина состояний (WORK → BROWSE → EDIT), обработка кнопок, дисплей.
- Обновление только при изменении данных — без мерцания.
