# Система управления давлением на Arduino Nano

Проект представляет собой систему автоматического управления двумя электромагнитными клапанами на основе показаний преобразователя давления (4-20 мА, 24В) с отображением информации и настройкой параметров через ЖК-дисплей 1602 I2C.

## Состав оборудования

- **Микроконтроллер**: Arduino Nano V3
- **Датчик**: Преобразователь давления 4-20 мА (питание 24В)
- **Исполнительные механизмы**: 2 электромагнитных клапана (24В)
- **Интерфейс**: ЖК-дисплей 1602 с модулем I2C
- **Управление**: Релейный модуль 2-канальный (5В)
- **Питание**: Блок питания 24В
- **Элементы схемы**: Резистор 240 Ом (прецизионный), кнопки тактовые (2 шт.)

## Функциональные возможности

1. **Считывание данных**: Преобразование токового сигнала 4-20 мА в значение давления.
2. **Гибкая настройка единиц измерения**:
   - Паскали (Па)
   - Килопаскали (кПа)
   - Мегапаскали (МПа)
   - Бары (бар)
   - Миллибары (мбар)
3. **Выбор диапазона измерения (Ранги)**:
   - 0...1
   - 0...40
   - 0...250
   - 0...400
   - 0...600
   - 0...1000
4. **Управление уставкой**: Установка пороговых значений для срабатывания реле с гистерезисом.
5. **Автоматическое управление**:
   - Клапан 1: Открытие при давлении ниже нижней уставки.
   - Клапан 2: Открытие при давлении выше верхней уставки.
6. **Интерфейс пользователя**:
   - Две строки дисплея: верхняя — меню/параметр, нижняя — значение/настройка.
   - Навигация и изменение параметров двумя кнопками.

## Схема подключения (кратко)

- **Датчик 4-20мА**: Подключается к 24В, сигнал через резистор 240 Ом на землю. Сигнал снимается с резистора на пин A0.
- **Реле**: Управление пинами D2 и D3. Питание катушек от 5В Arduino или внешнее (в зависимости от модуля). Силовая часть коммутирует 24В для клапанов.
- **Дисплей 1602 I2C**: SDA -> A4, SCL -> A5, VCC -> 5В, GND -> GND.
- **Кнопки**:
  - Кнопка 1 (Menu/Enter): Пин D4 (подтяжка к земле).
  - Кнопка 2 (Up/Change): Пин D5 (подтяжка к земле).

*Подробная схема доступна в файле `docs/connection.txt`.*

## Использование

1. Загрузите скетч `pressure_controller.ino` в Arduino Nano.
2. При включении система переходит в рабочий режим.
3. **Кнопка 1 (Короткое нажатие)**: Переключение пунктов меню (Режим -> Ранг -> Уставка -> Ед. изм.).
4. **Кнопка 1 (Длинное нажатие > 2 сек)**: Вход в режим редактирования текущего параметра / Сохранение и выход.
5. **Кнопка 2**: Изменение значения выбранного параметра в режиме редактирования.

## Настройка

Перед использованием необходимо откалибровать систему:
- Проверить соответствие минимального (4 мА) и максимального (20 мА) тока значениям в коде (`ADC_MIN`, `ADC_MAX`).
- Установить требуемый диапазон и единицы измерения через меню.
- Настроить уставки срабатывания реле.
