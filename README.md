# Контроллер давления на Arduino Nano

Проект контроллера давления для управления технологическими процессами на базе Arduino Nano V3. Устройство считывает сигнал 4-20 мА с преобразователя давления, отображает текущие значения на ЖК-дисплее 1602 I2C и управляет двумя электромагнитными клапанами через релейные модули.

## 🛠 Функциональные возможности

*   **Чтение датчика:** Поддержка преобразователей давления с токовым выходом 4-20 мА (питание 24 В).
*   **Управление нагрузкой:** Два независимых реле (D2, D3) для управления клапанами или насосами.
*   **Интерфейс:** ЖК-дисплей 1602 с модулем I2C.
*   **Настройки в реальном времени:**
    *   Выбор диапазона измерения (Ранг): 1, 40, 250, 400, 600, 1000.
    *   Выбор единиц измерения: Па, кПа, МПа, бар, мбар.
    *   Настройка уставок (Lower/Upper Setpoint) с индивидуальным гистерезисом.
*   **Калибровка:** Двухточечная калибровка (0% и 100%) прямо через меню для компенсации погрешностей резистора и датчика.
*   **Защита и диагностика:**
    *   Детекция обрыва цепи датчика (ток < 4 мА).
    *   Аварийное отключение реле при неисправности.
*   **Энергонезависимая память:** Все настройки (уставки, калибровка, ранги) сохраняются в EEPROM и не сбрасываются при отключении питания.
*   **Сброс настроек:** Возможность возврата к заводским параметрам через меню.

## 🔌 Схема подключения (Распиновка)

### Питание и Датчик
*   **БП 24В (+)** -> Питание датчика (+) и общий контакт реле (COM).
*   **БП 24В (-)** -> Земля (GND) Arduino, Земля датчика (-), Минус клапанов.
*   **Сигнал датчика** -> Резистор 240 Ом -> GND. Точка соединения -> **A0**.

### Периферия Arduino Nano
| Пин Arduino | Компонент | Описание |
| :--- | :--- | :--- |
| **A0** | Датчик (через резистор) | Аналоговый вход сигнала |
| **A4** | LCD SDA | Шина данных I2C |
| **A5** | LCD SCL | Шина тактирования I2C |
| **D2** | Реле 1 (IN1) | Управление Клапаном 1 |
| **D3** | Реле 2 (IN2) | Управление Клапаном 2 |
| **D4** | Кнопка MENU | Навигация / Вход / Подтверждение |
| **D5** | Кнопка CHANGE | Изменение значений / Калибровка |
| **5V** | LCD VCC, Реле VCC | Питание логики |
| **GND** | LCD GND, Реле GND, Кнопки | Общая земля |

## 🎛 Управление и Меню

Устройство имеет две кнопки:
1.  **MENU (D4):**
    *   *Короткое нажатие:* Переключение пунктов меню (в режиме просмотра) или переключение между нижней/верхней уставкой (в режиме редактирования).
    *   *Длинное нажатие (>2 сек):* Вход в режим редактирования текущего пункта или сохранение и выход из режима редактирования.
2.  **CHANGE (D5):**
    *   *Нажатие:* Увеличение значения выбранного параметра (циклический перебор).

### Структура меню
1.  **Mode:** Информационный экран (нормальный режим работы).
2.  **Range:** Выбор диапазона измерения (1...1000).
3.  **Setpoint:** Настройка уставок.
    *   `>L:` Нижняя уставка (включение реле 1).
    *   ` H:` Верхняя уставка (включение реле 2).
    *   *Отдельно настраивается параметр Гистерезиса.*
4.  **Unit:** Выбор единиц измерения (Pa, kPa, MPa, bar, mbar).
5.  **Calibr:** Режим калибровки.
    *   Калибровка нуля (подайте 4 мА / 0 давления).
    *   Калибровка максимума (подайте 20 мА / макс. давление).
6.  **Reset:** Сброс всех настроек к заводским значениям.

## ⚙️ Логика работы

*   **Реле 1 (Клапан 1):** Активно, когда давление ниже `Уставка Low - Гистерезис`. Отключается при достижении `Уставка Low`.
*   **Реле 2 (Клапан 2):** Активно, когда давление выше `Уставка High + Гистерезис`. Отключается при падении до `Уставка High`.
*   **Авария:** Если ток датчика < 4 мА (обрыв), на экране появляется ошибка `ERR BREAK`, реле отключаются.

## 💾 Память (EEPROM)

Настройки сохраняются автоматически при выходе из режима редактирования (длинное нажатие MENU).
*   Адреса EEPROM зарезервированы под: магическое число версии, ранг, единицы, уставки, гистерезис, коэффициенты калибровки.
*   При первом включении или после сброса загружаются значения по умолчанию.
