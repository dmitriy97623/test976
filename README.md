# Симулятор Arduino 4–20 мА

Графический симулятор сигнала 4–20 мА для тестирования ПО.

## Функции
- Эмуляция аналогового сигнала (АЦП, ток, давление)
- Виртуальные порты через `socat`
- Ручной и автоматический режим
- Обратная связь по клапану с гистерезисом
- Логирование, график, настройка порогов
- Выбор прошивки (режима работы)

## Установка
```bash
sudo dnf install socat        # или apt install socat
pip install -r requirements.txt
