СХЕМА ПОДКЛЮЧЕНИЯ ОБОРУДОВАНИЯ

1. ПИТАНИЕ И ЗАЗЕМЛЕНИЕ
-----------------------
- Блок питания 24В:
  * Плюс (+24В) -> Общий плюс для датчика и реле (COM).
  * Минус (0В) -> Общий минус (GND) для всей системы.
  
- Arduino Nano:
  * GND -> Соединяется с 0В блока питания 24В (ОБЯЗАТЕЛЬНО для общей земли).
  * 5В -> Питание дисплея и логической части реле (если модуль 5В).

2. ДАТЧИК ДАВЛЕНИЯ (4-20 мА, 24В)
---------------------------------
Схема включения токовой петли:
  +24В (БП) ---> [Плюс Датчика]
                 [Минус Датчика] ---> [Резистор 240 Ом] ---> GND (Общий)
                                            |
                                            +---> Аналоговый вход A0 (Arduino)

Примечание: Резистор должен быть прецизионным (точность 1% или лучше), мощность 0.5-1 Вт.
Напряжение на резисторе: 0.96В (4мА) ... 4.8В (20мА).

3. РЕЛЕЙНЫЙ МОДУЛЬ (Управление клапанами)
-----------------------------------------
Логическая часть (управление от Arduino):
  VCC -> 5В (Arduino)
  GND -> GND (Arduino)
  IN1 -> Пин D2 (Клапан 1)
  IN2 -> Пин D3 (Клапан 2)

Силовая часть (коммутация 24В для клапанов):
  Для каждого канала реле:
  * COM (Общий контакт реле) -> +24В (от Блока Питания).
  * NO (Нормально открытый) -> Плюс контакта Клапана.
  * Минус контакта Клапана -> 0В (GND Блока Питания).

*Рекомендуется использовать диоды (например, 1N4007) параллельно катушкам клапанов, 
если они не встроены в сами клапаны, для защиты контактов реле от индуктивных выбросов.*

4. ДИСПЛЕЙ 1602 I2C
-------------------
  VCC -> 5В (Arduino)
  GND -> GND (Arduino)
  SDA -> Пин A4 (Arduino Nano)
  SCL -> Пин A5 (Arduino Nano)

5. КНОПКИ УПРАВЛЕНИЯ
--------------------
Используются две тактовые кнопки с подтяжкой к земле (внутренней или внешней).
В данном проекте используются внутренние подтяжки Arduino (INPUT_PULLUP), 
поэтому кнопка замыкает пин на землю при нажатии.

  Кнопка 1 (MENU/ENTER):
  * Один контакт -> Пин D4 (Arduino).
  * Второй контакт -> GND.

  Кнопка 2 (UP/CHANGE):
  * Один контакт -> Пин D5 (Arduino).
  * Второй контакт -> GND.

6. ОБЩИЕ ТРЕБОВАНИЯ
-------------------
- Все соединения 24В выполнять проводом сечением не менее 0.5 мм².
- Линии сигналов (A0, SDA, SCL) желательно выполнять витой парой или экранированным проводом при длине более 20 см.
- Установить предохранитель 2-3А в цепь +24В перед распределением на нагрузку.
